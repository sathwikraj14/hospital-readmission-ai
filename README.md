
# Hospital Readmission Risk Prediction Using Machine Learning

## Project Overview
An end-to-end AI/ML project designed to predict the risk of hospital readmission within 30 days for patients with diabetes.

## Objectives
- Analyze healthcare data and identify patterns associated with readmission.
- Train and compare multiple machine learning algorithms.
- Optimize predictive performance using hyperparameter tuning.
- Explain predictions using SHAP.
- Build an interactive Streamlit web application.

## Machine Learning Models
- Logistic Regression
- Random Forest
- XGBoost
- LightGBM
- CatBoost
- Neural Network
- Stacking Ensemble

## Technology Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost, LightGBM, CatBoost, SHAP, Streamlit, Git, GitHub

## Project Status
In development.

## Disclaimer
This project is for research and educational purposes only. It is not intended for clinical decision-making.
